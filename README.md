# repo-setup

Giacomo's personal, repo-unaware setup skill: brings any repository (new or
existing) to the standard setup — ship pipeline, Multica issue tracking,
TDD/testing skills, docs skeleton + agent code map.

Deliberately **not** symlinked into `~/.claude/skills/` (invisible to normal
sessions). Invoke from any repo:

> read ~/virtual_desktop/projects/shared-agents/repo-setup/SKILL.md and run it
> (all phases | only phase X)

New machine: `git clone https://github.com/Geghi/repo-setup ~/virtual_desktop/projects/shared-agents/repo-setup`
