# v18 — query-flow-review

New skill `templates/skills/query-flow-review/SKILL.md`, copied verbatim: a flow-aware database round-trip reviewer. It traces the flow a diff lives in (route, cron, queue, worker), inventories every data-access request in execution order, and flags avoidable round trips — unnecessary split queries (prefer an embedded read or join), repeated reads, discarded data, N+1, refetch after `RETURNING` — passing each through the preference ladder reuse/elimination → embedded join → batching → RPC. It never proposes to cut a tenant filter, a validation or an audit write, and prefixes findings `introduced` / `worsened` / `existing-flow`. It works standalone or as a `/ship` specialist reviewer.
