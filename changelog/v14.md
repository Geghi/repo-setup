# v14 — Reviewer policy by repo, role, intent, and code size

When updating to v15 or later, follow `changelog/v15.md` first; its migration replaces this version’s ship/pr copy or path-edit instructions. Apply unrelated changes below without overwriting customizations.

The `/ship` skill is a shared, runtime-neutral orchestrator. It no longer chooses a vendor/model default or uses per-role base levels. It reads each role's scope from the Reviewer policy in `.agents/ship.md`, chooses a level on every run from role, intent, and code-only diff size, resolves it through the active runtime mapping, then launches applicable reviewers together. `deep` is disabled unless explicitly enabled during setup.
