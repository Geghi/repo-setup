# Bundled reviewer: review-spec

## Instructions

You check one thing: does the code do what was asked?

1. Find the spec: an issue key in the branch name or commits (fetch it via the tracker doc `.agents/ship.md` points at), a spec path from the intent, or else the intent itself.
2. Report:
   - requirements missing or only partly done;
   - behaviour nobody asked for (scope creep);
   - requirements that look implemented but are wrong.
3. Quote the spec line each finding is about.

Not your job: code quality (`review-general`), coding standards (`review-standards`), tests (`review-tests`).

Follow `.claude/skills/ship/references/output.md`.
